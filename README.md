# Retail Sales Exploratory Data Analysis

## Oasis Infobyte Data Analytics Internship

### Task 1 – EDA on Retail Sales Data

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to identify sales trends, customer behaviour, product performance, and relationships between numerical variables.

## Objectives

- Analyze the structure of the retail sales dataset
- Identify missing values and understand the data
- Calculate descriptive statistics
- Analyze monthly and quarterly sales trends
- Study customer demographics
- Identify top-selling product categories
- Analyze revenue by product category
- Study correlations between numerical variables
- Generate actionable business recommendations

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The project uses a supermarket/retail sales dataset containing information about transactions, customers, products, quantities, prices, and total sales.

## Analysis Performed

### 1. Data Inspection
- Dataset shape
- Column information
- Missing-value analysis
- Descriptive statistics

### 2. Time-Series Analysis
- Monthly sales trends
- Quarterly sales trends

### 3. Customer Analysis
- Gender distribution
- Customer age-group analysis

### 4. Product Analysis
- Top-selling products/categories
- Revenue by product category

### 5. Correlation Analysis
A correlation heatmap was created to identify relationships between numerical variables.
